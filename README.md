# Travel Agency Reservation System

A Java desktop application for managing travel agency reservations, built as an Object-Oriented Programming course project.

## About
This application allows users to browse and book trips and travel arrangements offered by a travel agency.

## Features
- View available trips and arrangements
- Make and manage reservations

## Technologies
- Java
- Object-Oriented Programming principles

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run `Main.java`
